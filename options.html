Tab Organizer

Custom rules, grouping threshold, and the Anthropic key for smart grouping.

General

With Smart on, new tabs are clustered by topic using Claude (incrementally, as you open them — see Smart grouping below for setup). With it off, tabs group instantly by website. Domains with fewer than the threshold of open tabs stay ungrouped (domain mode only).

Custom rules

Rules win over domain grouping. Match is a domain (github.com — also matches subdomains), a URL glob (https://*.figma.com/*), or a regex. Tabs sharing a group name merge into one group.

Smart grouping

Smart group clusters tabs by topic using Claude (model claude-haiku-4-5). It prefers your local Claude CLI — no API key, uses your existing Claude sign-in.

One-time setup: run native/install.sh from the extension folder in a terminal, then fully quit & reopen the browser.

Learned 0 sites

Smart mode remembers which group each site belongs to, so repeat sites are sorted instantly with no AI call. Clearing this makes it re-learn from scratch.

Optional fallback: Anthropic API key

Used only if the Claude CLI bridge isn't available. Stored locally on this device (not synced). Get a key at console.anthropic.com.

Privacy

Smart grouping sends tab titles + URLs to Claude. URLs are sanitised first — query strings and #fragments are stripped, so tokens in links are never sent. Incognito tabs are never sent.
